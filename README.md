# Data Strategy — Demo Set

A high-fidelity mockup walkthrough of the operating end-state of an 18-month
data strategy for **Meridian**, a fictional premium wellness brand. Five
product surfaces, one shared set of foundations.

**Live demo:** https://traversp.github.io/data-strategy-mockups/

> Meridian is illustrative — the brand, members, metrics and instructor
> names are fabricated to demonstrate what good looks like when a luxury
> wellness business operates on a properly governed data layer.

## What's in here

Five interactive HTML mockups, each demonstrating a different surface of
the same governed data platform:

| # | Artefact | Audience | What it shows |
|---|---|---|---|
| 01 | **GM Live Dashboard** | General Manager | Operational situational awareness — KPI hero strip, attention alerts, today's classes, member pulse, AI Observations panel |
| 02 | **Member 360** | Concierge / Retention / Exec | The resolved member, made visible — one canonical record across five source systems |
| 03 | **Churn Intervention Console** | Head of Membership | Retention workflow — ranked at-risk queue, behaviour trajectory, ML-suggested interventions with recovery rates |
| 04 | **Personalised Member App** | The member | What Sarah Jones sees on her phone — programme-aware recommendations, the new class slot added in response to her waitlist pattern |
| 05 | **Ask Meridian** | GM / Exec / Analyst | Natural language over governed data — cited sources, inline visualisations, awareness of competing KPI definitions |

The five artefacts share the same governed data layer. The same Sarah Jones
appears across all of them; the same metrics are the same certified
numbers; the same systems are the same source of truth. That continuity is
the entire point.

## How to use this

Start on the [navigator landing page](https://traversp.github.io/data-strategy-mockups/).
The recommended walkthrough takes 8 minutes and follows the order above
(01 → 05).

Each page has a **tour mode** that highlights clickable elements with small
bronze indicators. Toggle with the pill in the bottom-right corner, or
press `T`.

Best viewed on a laptop or larger screen (1440×900 or wider). The Member
App is designed for mobile-style framing but lives inside a desktop demo
canvas.

## Status
